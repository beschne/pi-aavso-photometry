`tools/fetch-vsp.py`. Each chart ID is the value for the AAVSO `CHART` report field.

## Regenerating

```bash
python3 tools/fetch-vsp.py --star "T CrB" --fov 450 --maglimit 14.5
```

AAVSO sequences are updated periodically. Regenerate before a major observing
campaign or if a chart looks stale.
